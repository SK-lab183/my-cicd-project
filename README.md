# CI/CD Pipeline with Docker & GitHub Actions

Автоматический пайплайн для сборки и деплоя веб-приложения (Nginx + Docker) на удаленный VPS-сервер.

## 🚀 Стек технологий
*   **CI/CD:** GitHub Actions
*   **Контейнеризация:** Docker, Docker Compose
*   **Веб-сервер:** Nginx
*   **ОС сервера:** Ubuntu 24.04
*   **Безопасность:** SSH-ключи (кастомный порт), UFW, Fail2Ban

## ⚙️ Как работает пайплайн
1.  Разработчик делает `git push` в ветку `main`.
2.  GitHub Actions запускает workflow (`.github/workflows/deploy.yml`).
3.  Файлы проекта по протоколу SSH (через `scp-action`) копируются на VPS.
4.  На сервере выполняется `docker compose up -d --build`.
5.  Сайт автоматически обновляется в продакшене.

## 🛡️ Безопасность (Security & Hardening)
Для защиты сервера от брутфорс-атак (подбора паролей) настроен **Fail2Ban**.
*   **Проблема:** Сервер в интернете ежедневно подвергается тысячам попыток взлома SSH (ботнеты из Азии и США).
*   **Решение:** Отключена аутентификация по паролю (вход только по SSH-ключам). Настроен `fail2ban`, который анализирует логи SSH и автоматически блокирует IP-адреса через `iptables` после 3 неудачных попыток входа (бан на 1 час).
*   **Результат:** Количество успешных подключений ботов сведено к нулю.

## 🔧 Решенные проблемы (Troubleshooting)
*   **Блокировка Docker Hub:** Столкнулся с таймаутом при скачивании базовых образов с официального Docker Hub. Решено переключением на зеркало (`cr.yandex/mirror/nginx:alpine`).
*   **Права доступа:** Настроены права `600` и `700` для директорий `.ssh` и ключей для корректного подключения GitHub Actions.
